# Product roadmap

The battle expansion is complete: 127 engagements with studies in six collections (Alexander, Rome, Napoleon, the First World War, the Serbian Front and the Second World War), 106 commander profiles, ten courses and fifteen decision exercises, with a readable atlas, collection pages, shareable catalog filters, campaign route maps, commander career strips and search by war, campaign and commander. The priorities below follow from it.

## Priority 1 — Editorial depth and evidence

1. Historian review of all 127 studies and 106 commander profiles. Extend section-level references to sentence-level citations with editions and page locators, add contrasting scholarship, and expand the brief study sections. Most studies (96 of 127) list three or four sources, mostly encyclopedic or institutional; the sixteen that listed only two were deepened in four batches (T1–T4), often with a source from the other side. Specialist histories and primary texts should come next.
2. Add substantive campaign narratives and war bibliographies; campaign pages are still indexes with a schematic map.
3. Develop battle-specific interpretive diagrams with documented geometry provenance; use georeferenced overlays only where source quality supports them. Preserve a text equivalent.
4. Review global periodization, command responsibility and transliteration consistently. Expand African, Asian, Middle Eastern and American coverage beyond the European-centred collections.

## Priority 2 — Curriculum and media

1. Specialist review of all ten learning paths, especially the five collection courses added in the expansion.
2. Add deeper quizzes (currently one question per lesson), advanced learning levels and source-criticism exercises; retain feedback rather than performance rankings. Candidate exercises not yet built include Teutoburg, Borodino, the Marne in 1914 and Market Garden.
3. Grow the nine-record media library: verified official video embeds beyond D-Day, more public-domain portraits, maps and primary documents, each with full attribution.
4. Give each commander profile and war page its own multi-source bibliography; add perspectives for Marathon.

## Priority 3 — Product and architecture

1. Reduce per-page payloads and add route-specific projections as the catalog grows; add Open Graph images for shared links.
2. Run Lighthouse on the published site and profile Core Web Vitals, including font, Motion and atlas costs; test with screen readers and high zoom.
3. Add progress export/import, optional accounts and cloud synchronization with explicit data ownership and privacy controls.
4. Add an editorial CMS with provenance, corrections, review status and audit history.
5. The static GitHub Pages site needs no runtime database. Migrate to PostgreSQL and a server deployment only if accounts or writes are added, with a backup strategy.

## Later

Teacher/classroom collections, multilingual content, richer campaign playback, achievements, moderated discussion and certificates. None should obscure the boundary between historical evidence and counterfactual teaching.
